💡 核心理念

别把 AI 当"工具"，把它当"CPU"。CPU 执行机器码 → LLM 执行自然语言指令；寄存器/缓存/RAM/磁盘 → LLM context / scratchpad / memory / archive；系统调用 → 工具调用；进程调度 → AgentLoop 调度。

📲 安装到安卓手机

这是一个 PWA APP，零后端依赖、离线可用、数据全部保存在本地浏览器。3 步装好：

1
本地开一个静态服务器：在项目根目录执行 cd apps/aios-learn && python -m http.server 8080 或 npx serve .。也可以直接用我们已经部署的 apps/aios-learn 子目录。
2
手机和电脑连同一个 Wi-Fi，Chrome 打开 http://电脑局域网IP:8080，等 1-2 秒让 Service Worker 注册完成。
3
Chrome 菜单 → "添加到主屏幕"，或菜单 → "安装应用"。安装后有独立图标、全屏运行、离线可用。

📦 或者：打包成原生 APK

如果你有 Android Studio 或 Capacitor CLI，也可以把这个 PWA 打包成带原生图标和启动屏的 APK。

npm i -D @capacitor/cli @capacitor/android
npx cap init aios-learn com.tgt.aioslearn
npx cap add android
cp apps/aios-learn/* www/
npx cap sync android
npx cap open android
